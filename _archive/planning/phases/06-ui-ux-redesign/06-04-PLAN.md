<action>

完全重写 `app/dashboard/dashboard-content.tsx`。去掉所有 LayerTabs 和 SubTabs 引用。保留 SlicerBar + Dashboard 内容的新布局。

**导入替换**：
- 移除：`import FilterTabs from "@/components/ui/FilterTabs"`、`import LayerTabs`、`import SubTabs` 以及 `OVERVIEW_SUBTABS, ANALYSIS_SUBTABS, GEO_SUBTABS, DETAIL_SUBTABS, type SubTab`
- 移除：`MapView dynamic import`（地图不再作为 LayerTabs 的子页面嵌入）
- 移除：`type CityMarker` 导入（地图不再嵌入）
- 新增：`import SlicerBar from "@/components/dashboard/SlicerBar"`
- 新增：`import EmptyState from "@/components/ui/EmptyState"`

**状态管理**（保留现有 URL searchParams + useState 模式）：
- 保留：`useSearchParams`, `useRouter`, `useState`, `useEffect`, `useRef`, `useCallback`
- 保留：filter state（`selectedL2`, `selectedRelations`, `selectedMds`, `selectedL1`）
- 保留：`buildQueryString`, `fetchData`, data/loading/error 状态
- 移除：`activeLayer`, `activeSub` 状态（不再需要 Layer/SubTab）
- 移除：`mapMarkers`, `mapLoading` 状态（地图不再嵌入）

**布局结构**（从上到下，单页滚动）：

```
<SlicerBar />      — sticky, 始终顶部
<KpiCardRow />     — lg:grid-cols-4 响应式网格
<div className="lg:grid lg:grid-cols-2 gap-6">  — lg 断点以上并排
  <TrendChart />
  <IndustryPieChart />
</div>
{brandsCount > 0 && (
  <CollapsibleBrandSection>   — 折叠/展开，显示品牌数
    <BrandTable />
  </CollapsibleBrandSection>
)}
```

**BrandTable 折叠**：
- 在 BrandTable 上方添加一个切换按钮，默认展开状态。
- 按钮显示格式："品牌列表 ({brandsCount})"，点击展开/折叠。
- 使用 `ChevronDown / ChevronRight` 箭头图标指示状态。
- 折叠/展开使用简单的 `useState` + 条件渲染，不需要动画复杂逻辑。

**Loading 状态**（初始加载，`!data` 且 `isLoading`）：
- 显示 SlicerBar skeleton + KpiCardRow skeleton + TrendChart skeleton + IndustryPieChart skeleton
- 不显示品牌列表

**Error 状态**（`error && !data`）：
- 保留现有 error 显示 + 重试按钮

**Empty 状态**（`data.brands.length === 0`）：
- 使用 `EmptyState` 组件（来自 Plan 03）
- icon: 使用 `<SearchX size={48} className="text-gray-300" />`
- message: "当前筛选条件下没有匹配的展会数据"
- action: 清除筛选按钮，onClick 重置所有 filter state

**Populated 状态**（有 data，`data.brands.length > 0`）：
- 渲染 SlicerBar → KpiCardRow → TrendChart + IndustryPieChart grid → BrandTable

**根据 CONTEXT.md Locked Decisions**：
- L1 行业筛选在 SlicerBar 中（已在 Plan 01 实现）
- 4 卡片横排带 hover 效果（在 KpiCard/KpiCardRow 中已有实现 + Plan 02 图标增强）
- 趋势图和饼图在 lg 断点以上并排（grid-cols-2）
- 空状态用 EmptyState（Plan 03 创建）
- Loading 骨架屏保持现有风格

**不包含**：
- 地图嵌入（地图保留为 sidebar 导航到 /map 页面）
- 任何 "开发中" 占位内容
- 任何高级分析 feature（heatmap, export, search 等）
</action>
