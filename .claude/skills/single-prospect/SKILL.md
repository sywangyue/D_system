## 单一客户深度调研任务

**目标**: $ARGUMENTS

---

## 第一步：从 DB 获取目标公司参展轨迹（禁止虚构）

> 以下数据自动注入，来自 mwlab.db。查询 organizer 字段和品牌名称进行模糊匹配。
> 若公司名称较通用（如"上海机床"），DB 可能返回多条相关展会，请全部纳入分析。

!`python3 tools/intel/db_query.py company-history "$ARGUMENTS"`

---

## 第二步：企查查工商信息查询

执行企查查模糊搜索获取工商信息：

```bash
python3 tools/intel/qcc_client.py "$ARGUMENTS" --size 3
```

**降级说明**：若 QCC_APP_KEY 未配置，输出"[企查查未配置]"，请继续执行，在报告的企业工商信息章节注明"企查查未配置，以下信息来自 WebSearch"。

---

## 第三步：WebSearch 补充信息

使用 WebSearch 搜索以下内容：

1. `"$ARGUMENTS" 公司 展览代理 资质`（代理商资质核查）
2. `"$ARGUMENTS" 公司 纠纷 违规 骗局`（风险信息）
3. `"$ARGUMENTS" 公司 近况 业务`（最新动态）
4. 若是协会：`"$ARGUMENTS" 协会 会员 主办展会`
5. 若是大型企业：`"$ARGUMENTS" 股权 法人变更`

---

## 第五步：保存报告到 DB

```bash
python3 tools/intel/report_writer.py \
  --type single_prospect \
  --target-company "$ARGUMENTS" \
  --content "$(cat /tmp/single_report.md)"
```

> 注意：联系人信息（如找到具体联系人）可手工录入 person + exhibition_contact 表（D-22 约定），本 Skill 不自动写入（无法从 WebSearch 可靠提取结构化联系人数据）。

执行成功后输出 `报告已写入 → intel_report.id = <N>`。

---

## 注意事项

1. **DB 无匹配不等于无记录**：DB 基于 organizer 字段搜索，品牌下无主办方字段时可能漏查
2. **企查查精确匹配**：若搜索结果返回多家同名公司，选择注册地和业务范围最匹配的一家
3. **风险标注必做**：即使 WebSearch 无负面信息，也必须在报告中明确标注"未发现风险信号"
4. **人工触发**：本 Skill 为人工触发，不做批量自动化执行
5. **联系人数据**：若调研中发现具体联系人，在报告正文记录，不写入 DB（person 表需人工维护）
