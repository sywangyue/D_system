<action>

创建 `components/ui/EmptyState.tsx`，这是一个可复用的空状态组件。

**Props:**
```typescript
import { Inbox } from "lucide-react";

interface EmptyStateProps {
  icon?: React.ReactNode;   // 可选自定义图标，默认使用 lucide Inbox
  message: string;           // 空状态消息文本
  action?: {                 // 可选操作按钮（如"清除筛选"）
    label: string;
    onClick: () => void;
  };
}
```

**默认图标样式**：`Inbox` 图标（来自 lucide-react），尺寸 `w-12 h-12`，颜色 `text-gray-300`（淡灰色）。

**布局**：flex column 居中（`flex flex-col items-center justify-center`）。
- 顶部：图标（默认 Inbox 或自定义 icon prop）
- 中间：`message` props 的文字，使用 `text-sm text-text-secondary mt-4`
- 底部（可选）：如果 `action` prop 存在，渲染一个 `<button>` 用于操作（如"清除筛选条件"），使用 `text-xs text-accent hover:text-accent-dark underline`

**SaaS 质感**：`py-16` 垂直内边距。整个容器高度自适应。

**导出**：
```typescript
export default function EmptyState({ icon, message, action }: EmptyStateProps) { ... }
```

**关键规则**：
- 组件必须是 "use client"（因为接收 onClick 回调）
- icon 容器有 `mb-2` 间距
- action 按钮使用 Tailwind `cursor-pointer`
</action>

<action>

更新 TrendChart 的容器样式以使用新的设计系统 CSS 变量：

1. 将容器 `className` 中的 `shadow-sm` 替换为使用 CSS 变量的 shadow。具体来说，从：
   ```
   className="bg-white border border-border rounded-xl p-5"
   ```
   改为：
   ```
   className="bg-white border border-border rounded-xl p-5 shadow-[var(--shadow-sm)]"
   ```

2. 保持所有其他现有样式不变。特别是：
   - Bar 的 fill 保持 `#fe5c00`
   - Bar 的 radius 保持 `[4, 4, 0, 0]`
   - XAxis/YAxis tick 配置不修改
   - Tooltip contentStyle 不修改
   - ResponsiveContainer 配置不修改

3. 标题 `<h3>` 使用 `text-text-primary` 语义 token 确保颜色与设计系统一致。当前已经是 `text-text-primary`，照常使用。

4. 如果 data 为空的空状态，保持现有 `"暂无趋势数据"` 文字，但应用 `text-sm text-text-secondary` 类（当前已有）。

**修改范围**：仅容器 div 的 className。不修改任何功能逻辑、不修改 recharts 配置、不修改数据格式化。
