## 1. 任务背景

杜塞尔多夫展览（Messe Düsseldorf）BD 将参加 **2026 年 8 月 12–13 日在上海张江科学会堂举办的第七届会展三新展**。该展是中国会展行业的年度大集，参会者中有大量同行主办方。

**明确排除**：与杜塞构成竞争关系的国际主办机构（Koelnmesse、RX Global / 励展、Informa / 英富曼、Messe München / 慕尼黑展览、Messe Frankfurt / 法兰克福展览、Hannover Milano / 汉诺威米兰、GL events / 智奥会展、Hyve、ITE、博华展览、博罗那展览，以及杜塞自己）。

### 3.1 输入文件

| 文件 | 用途 |
|---|---|
| `待调研清单.csv` | **主输入**，262 行，已按优先级排序，含 mwlab 已知线索，直接逐行填写 |

| `queue.json` | 483 家全量，含排除理由，用于最终报告的「已排除」sheet |

### 3.2 每家机构的调研动作

对 `待调研清单.csv` 的每一行执行：

**第一步 · 搜索**（每家 1–2 次，中文搜索引擎或 WebSearch）

```
主查询：{机构全称} 主办 展会
备查询：{机构全称} 自办展 展览会 主办单位
补充：  {机构简称} 官网      （当主查询无果）
```

**第二步 · 判定「是否自办展」**，三档：

| 取值 | 判定标准 |
|---|---|
| `是` | 有明确以该公司为**主办单位**的展会/大会，且非一次性活动 |
| `部分` | 只做**承办**（主办是协会/政府），或仅有会议无展览，或 IP 归属他人 |
| `否` | 只做搭建、执行、场馆出租、代理出国展、技术服务 |
| `待核` | 公开信息不足以判断（**不要猜，标待核，写进"现场必问"清单**） |

> **反面教材**：不要因为公司名里有「会展/展览」就判为「是」。名单里大量「XX展览服务有限公司」实际只做搭建或主场服务。必须找到具体展会名称+主办单位署名才能判「是」。

**第三步 · 填写字段**

| 字段 | 填写要求 |
|---|---|
| 归属集团 | 母公司/实控人，注明国资/民营/外资/协会/央企 |
| 主体类型 | 主办方 / 场馆运营 / 场馆+主办 / 协会 / 政府 / 承办服务商 / 搭建 / 媒体 / 技术服务 |
| 自办展项目 | 展会全称，多个用分号隔开，尽量带届数 |
| 主赛道 | 行业，如「机床/金属加工」「养老康复」「食品包装」 |
| 规模证据 | 展览面积㎡ / 展商数 / 观众数 / 届数，**必须是搜到的原文数字，不许估算** |
| UFI认证 | 是 / 否 / 部分 / 未知 |
| 来源URL | 支撑结论的链接，至少 1 条，多条用分号隔开 |

**第四步 · 打分**

**收购潜力（1–5）**——衡量「能不能买、值不值得买」：

| 分 | 标准 |
|:--:|---|
| 5 | 民营 + 多个成熟自有 IP（≥2 个 3万㎡级或 ≥5 个中型）+ 股权结构简单 |
| 4 | 民营 + 单一赛道深耕的清晰 IP + 有跨城复制能力；或已挂牌（新三板）可尽调 |
| 3 | 民营小型主办方，IP 单一或体量小；或 IP 归属在协会手里需理清 |
| 2 | 承办型 / 无自有 IP / 区域执行伙伴 |
| 1 | 国资、央企、协会、政府、上市公司主体——**不可收购，但可能是重要合作方** |
| 0 | 信息不足或与本任务无关 |

**战略契合度（1–5）**——衡量「和杜塞的业务有多近」。杜塞主赛道加权：

| 杜塞展会 | 对应中国赛道 |
|---|---|
| MEDICA / COMPAMED | 医疗器械、医疗健康 |
| REHACARE | 康复辅具、养老、无障碍 |
| drupa | 印刷、包装、纸业 |
| K | 塑料、橡胶 |
| GIFA / METEC / THERMPROCESS / NEWCAST | 铸造、冶金、热处理 |
| wire / Tube | 线缆、管材、金属加工 |
| ProWein | 葡萄酒、烈酒、食品饮料 |
| boot | 船艇、水上休闲 |
| interpack | 包装、食品加工机械 |
| A+A | 劳保、职业安全 |

| 分 | 标准 |
|:--:|---|
| 5 | 主营赛道与上表**直接对应** |
| 4 | 赛道邻近或产业链上下游（如金属产业链媒体之于 GIFA） |
| 3 | 有部分交集的子板块 |
| 2 | 无赛道交集，但有区域平台/渠道价值 |
| 1 | 无交集无渠道价值 |

**合作切入点**：一句话写清「能跟他谈什么」。例：
- 「已是法兰克福展览合资方，同模式可复制到杜塞项目」
- 「手握 200 个出国展代理渠道，是德国本土展中国组团的天然渠道」
- 「AID 与 REHACARE 同赛道同定位，谈品牌授权联办」

### 3.3 批次划分

## 5. 执行注意事项

1. **不许编造**。搜不到就写 `待核`，进「现场必问」sheet。规模数字必须有原文出处。
2. **区分主办与承办**。中国展会普遍是「协会主办 + 公司承办」，真正的商业价值和 IP 控制权往往在承办方手里，但也可能不在——两边都要写清楚。
3. **同一主体多个写法要合并**。名单里存在「东浩兰生」「东浩兰生会展集团」「上海东浩兰生会展（集团）有限公司」「上海东浩会展经营有限公司」这类同源条目，`results.jsonl` 里已合并处理，剩余部分继续沿用。
4. **发现新的国际同行要补排除**。执行中若发现某机构实为国际主办方的中国实体（本轮就漏过「智奥会展 = GL events」），标记为排除并在报告里注明。
5. **微信公众号链接会触发验证码**，不要在这上面耗时间，名单已全部提取完毕。
6. **mwlab 库覆盖不全**。例如华墨集团在库里只匹配到 1 条（印尼食品展），但它实际是民营办展规模第一、旗下有华夏家博会/华机展/华车展。**库里没有 ≠ 没有自办展**，一切以网络搜索为准，库只作交叉验证。

### mwlab 线索的可信度分级

`待调研清单.csv` 的「mwlab已知展会」列按可信度取值：

| 显示形式 | 含义 | 处理方式 |
|---|---|---|
| 直接列出展会名 | 精确匹配或 organizer 字段全文命中 | 可信，直接采用 |
| `（模糊匹配，需核实）...` | 包含匹配得出，可能张冠李戴 | **必须用网络搜索验证后才能写进报告** |
