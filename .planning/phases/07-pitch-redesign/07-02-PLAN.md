## Objective

Redesign the top half of `public/pitch.html` following Salesforce landing page design language:
- Simple, clean, lots of whitespace
- Only necessary content visible
- Product screenshots in clean frames (not heavy CSS animation mockups)
- Bold typographic hierarchy, left-aligned content, no decorative excess

Three changes:
1. Simplify Navbar — remove dropdown and budget link, keep logo + lang + single CTA
2. Add "MWLAB 是什么" intro section with a clean product screenshot mockup (laptop + phone)
3. Replace 4-column capability grid with 4 full-width alternating rows (SFDC pattern)

## Design Language: SFDC Reference

Salesforce landing pages use:
- **Backgrounds**: White (#FFFFFF) primary, light gray (#F5F5F7) for alternating sections
- **Typography**: Very large, bold left-aligned headlines; brief 1–2 line descriptions
- **Layout**: Max-width ~1200px centered container; generous padding (80–100px vertical)
- **Product frame**: Screenshot in a white card with subtle `box-shadow: 0 4px 24px rgba(0,0,0,0.10)` and `border-radius:12px`
- **NO**: heavy animations, complex CSS mockups, gradients, dark hero backgrounds (touch nothing in existing hero though)
- **Content rule**: Each section has ONE headline + ONE short paragraph + optional bullet list. Nothing more.

Existing color palette is PRESERVED:
- `--accent: #FE5C00` (buttons, eyebrow text, dots)
- `--text: #1D1D1F` (headings)
- `--text2: #6E6E73` (body)
- `--surface: #F5F5F7` (section backgrounds)
- `--card: #FFFFFF`
