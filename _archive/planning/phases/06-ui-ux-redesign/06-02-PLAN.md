**KpiCard.tsx 修改：**

1. 在 `KpiCardProps` 接口中新增可选 `icon?: React.ReactNode`
2. 在 label 行上方渲染图标（如果 icon 存在）：
   ```
   {icon && <span className="...">{icon}</span>}
   {!icon && label在一定场景适用}
   ```
   实际场景：icon 放置在 label 上方或左侧。如果是上方：需要一个 `w-8 h-8` 的图标容器，颜色使用 `text-accent`（MD 橙色系，与 highlight variant 保持一致）。
   
   具体渲染位置：在 label 之上添加一个图标行。图标使用 `w-8 h-8 text-accent` + `mb-2` 间距。

   对于 highlight variant：图标使用 `text-accent-dark`。
   对于 standard variant：图标使用 `text-accent`。

3. 在 loading skeleton 中添加图标占位符（保持现有结构不变，只是额外加一个 pulse 行）。
4. 在 empty state 中不需要显示图标。
5. **关键：不修改 `formatNumber` 函数，不改变 value 渲染方式，不改变 TrendBadge 渲染方式。**

**KpiCardRow.tsx 修改：**

1. 从 `lucide-react` 导入四个图标：`Square, Users, Eye, Building2`
2. 向每个 KpiCard 传入对应的 icon：
   - `面积` → `<Square size={32} />`
   - `展商数` → `<Users size={32} />`
   - `观众数` → `<Eye size={32} />`
   - `主办方` → `<Building2 size={32} />`
3. 将第四卡片 label 从 `"展览集团"` 改为 `"主办方数"`
4. 保持所有其他 props 不变（value, unit, trend, variant, isLoading）

**导入路径检查**：确认 `lucide-react` 中的 `Square`, `Users`, `Eye`, `Building2` 图标均存在于 `lucide-react@0.532.0`。如果某个图标不存在，使用备用图标名（`LayoutGrid` 替代 `Square`，`UserCheck` 替代 `Users` 等）。在代码注释中注明使用的图标名。

<action>

为 IndustryPieChart 的 Donut 饼图添加中心总数 Label。使用 recharts 的 `Label` 组件（已经导入的组件无需额外依赖）。

修改步骤：

1. 在文件顶部的 recharts 导入中，确认包含 `Label`：
   ```typescript
   import { PieChart, Pie, Cell, Tooltip, Label } from "recharts";
   ```

2. 在 `<Pie>` 组件内部（作为子元素），添加 `<Label>` 组件：
   ```tsx
   <Pie data={data} ...>
     <Label
       content={({ viewBox }) => {
         if (!viewBox || !data.length) return null;
         const total = data.reduce((sum, d) => sum + d.value, 0);
         const { cx, cy } = viewBox;
         return (
           <text x={cx} y={cy} textAnchor="middle" dominantBaseline="central">
             <tspan
               x={cx}
               dy="-0.3em"
               fontSize="26"
               fontWeight="700"
               fill="#111827"
             >
               {total.toLocaleString("en-US")}
             </tspan>
             <tspan
               x={cx}
               dy="1.5em"
               fontSize="12"
               fontWeight="400"
               fill="#6B7280"
             >
               品牌
             </tspan>
           </text>
         );
       }}
     />
   </Pie>
   ```

3. 确保 label 在数据为空时不渲染（content 函数中已有 `if (!viewBox || !data.length) return null`）

4. **保留所有现有功能**：l2ByL1 折叠面板 不修改、renderLabel 不修改、CHART_COLORS 不修改、tooltip 不修改、empty/loading/error state 不修改。

5. **关键约束**：只在 populated state（有 data）时显示 center label。Loading、error、empty 状态不包含 Label。

**验证方法**：渲染后，饼图中央应显示大号数字 + "品牌" 字样。
</action>
