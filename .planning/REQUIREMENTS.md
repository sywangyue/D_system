# MWLAB-2026 — Requirements

## Phase 5: 情报后端

| ID | Category | Requirement | Priority |
|----|----------|-------------|----------|
| REQ-01 | 行业调研 | 根据品类/行业标签从 DB 聚合该行业展会列表（展会数量、规模、频次、主办方分布） | P0 |
| REQ-02 | 行业调研 | 结合 WebSearch 补充该行业的市场趋势、发展现状 | P0 |
| REQ-03 | 行业调研 | 输出行业竞争格局分析：头部玩家、切入点位、TAM 估算方法 | P0 |
| REQ-04 | 行业调研 | 使用方法论（如 TAM/SAM/SOM 框架、Porter 五力）校验可进入性 | P1 |
| REQ-05 | 行业调研 | 调研结果沉淀到 DB（industry_research 表） | P0 |
| REQ-06 | 品牌展会调研 | 从 DB 拉取目标品牌完整历史届次数据（年份、规模、地点、增长趋势） | P0 |
| REQ-07 | 品牌展会调研 | 分析竞争关系：同行业竞品展会列表、面积/展商/观众对比 | P0 |
| REQ-08 | 品牌展会调研 | 调研主办方背景：关系网络、股权结构（WebSearch + 企查查 API） | P1 |
| REQ-09 | 品牌展会调研 | 输出战略评估：是否值得合作/收购/竞争，支撑 BD 谈判 | P0 |
| REQ-10 | 品牌展会调研 | 调研结果沉淀到 DB（brand_research 表） | P0 |
| REQ-11 | 批量客户挖掘 | 从 DB 获取目标竞品展会的参展商名单 | P0 |
| REQ-12 | 批量客户挖掘 | 接入企查查 API 进行参展商信息扩充（企业规模、联系方式、行业标签） | P0 |
| REQ-13 | 批量客户挖掘 | 支持模糊搜索匹配（公司名、品牌名、产品关键词） | P0 |
| REQ-14 | 批量客户挖掘 | 批量结果导出（Excel/CSV）供 BD 使用 | P0 |
| REQ-15 | 批量客户挖掘 | 挖掘结果沉淀到 DB（customer_prospect 表） | P0 |
| REQ-16 | 单一客户挖掘 | 针对单一目标（协会/公司/代理机构）做深度调研 | P0 |
| REQ-17 | 单一客户挖掘 | 调取目标公司所有相关参展记录（跨展会、跨年份） | P0 |
| REQ-18 | 单一客户挖掘 | 接入企查查 API 获取工商信息、关联企业、法人信息 | P1 |
| REQ-19 | 单一客户挖掘 | 输出客户画像：展会参与轨迹、潜在需求、风险标注（违规代理排查） | P0 |
| REQ-20 | 单一客户挖掘 | 调研结果沉淀到 DB（customer_profile 表） | P0 |
| REQ-21 | Skill 系统 | 每个调研模块写为 Claude Code skill，支持复用和迭代优化 | P0 |
| REQ-22 | Skill 系统 | Skill 以展会品牌 (brand_id/edition_id) 为核心输入参数 | P0 |
| REQ-23 | 数据约束 | 所有展会基础数据必须来自 mwlab.db，禁止 LLM 虚构 | P0 |
| REQ-24 | 触发方式 | 全部操作为人工触发（项目组邮件确认后手动执行） | P0 |
| REQ-25 | 结果格式 | 调研报告输出为结构化 Markdown（便于阅读和归档） | P1 |
