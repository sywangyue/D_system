      setError(null)

    - 展览集团（standard 变体）：kpi.organizer_count

    **PieChart 数据**：
    - API 返回的 industryDistribution → 直接传入 IndustryPieChart 的 data prop

    **空状态**（data.brands.length === 0）：

    interface DashboardData {
