创建 `components/dashboard/SlicerBar.tsx`，实现 Excel 切片器风格的行业筛选组件。

**Props 接口**（与现有 FilterTabs 保持回调兼容，但视觉完全重做）:
```typescript
interface SlicerBarProps {
  // Industry L1 — 切片器按钮组
  industryL1Options: string[];
  selectedL1: string | null;
  onL1Change: (value: string | null) => void;

  // Industry L2 — 展开面板中的多选标签
  industryL2Options: string[];
  selectedL2: string | null;
  onL2Change: (value: string | null) => void;

  // Competition relation — 多选
  competitionRelationOptions: string[];
  selectedRelations: string[];
  onRelationsChange: (values: string[]) => void;

  // MDS related — 单选
  mdsRelatedOptions: string[];
  selectedMds: string | null;
  onMdsChange: (value: string | null) => void;

  isLoading?: boolean;
}
```

**视觉规范**:
1. **L1 切片器行**：按钮为矩形（非圆角胶囊），类似 Excel 数据透视表的切片器。MD 橙色填充为选中态，灰色边框为未选中态。文字水平居中排列。按钮之间间距 4px。
2. **L2 展开面板**：选中某个 L1 后，在其下方展开一个面板，包含该 L1 下的所有 L2 选项。L2 使用圆角标签（pill）样式，可多选。同一时间只能展开一个 L1 的面板（手风琴行为）。
3. **竞争关系行**：在 L2 面板下方，视觉弱化（更小字体、更浅灰色背景），与现有 FilterTabs 行为一致但更紧凑。
4. **MDS 相关性行**：在竞争关系行下方，同样视觉弱化。
5. **Sticky 容器**：整个 SlicerBar 使用 `position: sticky; top: 0; z-index: 10`。白色背景 + 极小 box-shadow 分隔线。

**按钮状态**: "全部" 按钮保持独立。L1 选中 → 显示 L2 面板。再次点击同一 L1 → 取消选中。

**交互规则**:
- `onL1Change(null)` 清除 L1 和 L2 选中
- `onL2Change(null)` 清除 L2 选中（保留 L1 选中）
- 竞争关系：点击切换选中/取消，[] 表示"全部"
- MDS：点击选中，null 表示"全部"

**SaaS 质感**:
- L1 按钮使用 `--radius-sm`（6px）圆角
- L2 标签使用 `--radius-md`（8px）圆角
- hover/active/focus 使用 `transition-colors duration-150`
- 选中态使用 `--color-accent-surface` 背景 + `--color-accent-dark` 文字

**实现参考**: 从现有的 IndustryPieChart.tsx 中 l2ByL1 的折叠/展开逻辑（L1 header + L2 items pattern）和 FilterTabs.tsx 中的回调逻辑继承。

导出命名: `export default function SlicerBar`，组件文件名 `SlicerBar.tsx`。
