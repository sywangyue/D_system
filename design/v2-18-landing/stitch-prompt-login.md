# 给 Stitch 的 Prompt · 登录页改版

**配图**：`current/login-now.png`（现状）+ workbuddy 登录页截图（参考 logo 的位置处理）
**用法**：发 Prompt A，不满意用 Prompt B 局部再要。

---

## Prompt A

```
你是资深产品设计师。重做一个 B2B 数据平台的登录页。

【产品】
MWLAB 万象 —— 杜塞尔多夫展览（Messe Düsseldorf）上海公司的内部 BD 工作台。
只有内部员工能登录，账号由管理员分配，没有注册、没有第三方登录、没有找回密码。
气质：克制、专业。不是消费级产品。

【现状问题】
见附图：现在是左右分栏，左边白底堆了一大堆信息（品牌字标、大标题、四个统计数字、
版权信息），右边灰底放表单。信息太多，登录页不需要讲这些。

【要做成什么样】

■ 布局：整页一张画布，不再分左右两栏
背景是**轻量化的 3D 几何元素**，主色用品牌橙 #fe5c00。
登录窗口是一个白色矩形卡片，带阴影，浮在画布中央。

■ 3D 几何背景的要求
- 轻量、克制，不是炫技。几何体稀疏分布，大量留白
- 形态用简单的立体基元：立方体、板片、圆柱、球，不要复杂模型
- **橙色是主色但不铺满整屏**：橙色几何体占画面一小部分，其余是白与浅灰的几何体，
  靠橙色几何做视觉焦点。整体明度偏亮，不许压暗
- 几何体不能压住中央的登录卡片，卡片周围要留干净的空间
- **必须用纯 CSS 或内联 SVG 实现，不要用位图、不要用 WebGL/three.js**
  （这是内部系统，加载速度优先，而且要能在代码里直接维护）

■ 文字：只保留三行，全部居中在卡片上方或卡片内
  上方小字：Powered by Claude
  中心文字：欢迎登录万象系统
  下方小字：强战略驱动看板
把现在左栏的品牌大标题、四个统计数字、版权行全部删掉。

■ 登录卡片
- 白色矩形，圆角 8px，明显的投影（浮起感）
- 里面从上到下：品牌 Logo → 三行文字 → 邮箱输入框 → 密码输入框 → 登录按钮 → 一行提示
- 输入框：浅灰底或白底带边框，圆角 4px，高度 40px 左右
- 登录按钮：**深黑底白字**，占满卡片宽度，圆角 4px
  （橙色留给背景几何体，按钮用黑白高对比，不要做成橙色按钮）
- 底部一行灰色小字：账号由管理员统一分配

■ Logo 兼「回到主页」入口
卡片顶部放品牌 Logo（橙色方块 MWLAB + 竖线 + 衬线体「万象」），它同时是回官网首页的链接。
参考 workbuddy 登录页把 logo 放在表单顶部的处理方式。
hover 时给一点反馈（轻微上移或透明度变化），暗示它可以点。

■ 右上角保留语言切换：ZH / EN 两个文字按钮，当前语言加重，另一个弱化

■ 必须画出的状态
1. 默认态
2. 输入框聚焦态（边框加深）
3. 错误态：输入框上方出现一条淡红色提示条，文案「邮箱或密码不正确」
4. 提交中：按钮文字变为「登录中…」且不可点

【颜色 · 只能用这些】
品牌橙 #fe5c00（只给背景几何体与 Logo）
白 #ffffff　　浅灰面 #fafafa　　输入框底 #f2f2f2　　hover #e6e6e6
发丝线 rgba(0,0,0,0.08)
主文字 #171717　正文 #4d4d4d　次要 #8f8f8f　最弱 #a8a8a8
按钮 底 #171717 / 字 #ffffff
错误态 底 hsl(0 100% 97%) / 边 hsl(0 90% 92%) / 字 hsl(358 66% 48%)
**不要引入第二个强调色**（不要蓝、绿、紫）。

【中文排版 · 必须遵守】
1. 中文字重比拉丁低一档（拉丁 600 时中文 500）
2. 中文绝对不用负字距
3. 中文行高比拉丁高：拉丁 1.4，中文 1.6
4. 中英混排时中文字号比拉丁小 1px
5. 数字用拉丁等宽字体
6. 中文标题不用 800 字重

【字号】11 / 13 / 15 / 18 / 24 / 28 / 44 px，中文各小 1px。
中心文字「欢迎登录万象系统」用 28px 级别，上下两行小字用 13px 级别。

【圆角】卡片 8px，输入框与按钮 4px。

【绝对不要做的】
- 不要注册入口、第三方登录（Google/GitHub/微信）、找回密码、记住我
- 不要插画、吉祥物、人物、照片
- 不要把登录按钮做成橙色
- 不要用 Material Design 的配色和组件语言
- 不要编任何数据或文案，文字就上面那几行

输出 1440×900 桌面版，四个状态各一张。
```

## Prompt B · 局部再要

```
只改【某一处】，其余保持不变。

不满意：（具体说，例如「几何体太密，卡片周围不干净」「橙色面积太大，整屏发燥」）
想要：（具体说，例如「几何体减一半，橙色只留 2–3 个体块」）

约束不变：颜色只能用之前那套，按钮保持黑白，纯 CSS/SVG 不用位图，中文不用负字距。
```

## 拿到稿子先自查

| 检查 | 不过关的表现 |
|---|---|
| 橙色面积 | 整屏发燥、卡片被橙色包围、按钮变成橙色 |
| 卡片周围是否干净 | 几何体压到卡片边缘或穿过卡片 |
| 背景实现方式 | 稿子里引用了 `.png` / `.jpg` 位图，或用了 three.js |
| 中文挤不挤 | 字贴在一起 = 套了负字距 |
| 多余的入口 | 出现注册、第三方登录、找回密码 |
| 四个状态齐不齐 | 只给了默认态 |

## 落地时我这边要处理的（不用写进 prompt）

- **门禁要改**：`QC.md` 第 1.2 节「界面不碰品牌橙」现在会拦下这个设计。
  收窄为「产品界面内部不碰品牌橙；登录页与落地页可用」，同步改 `DESIGN.md`。
- **必须保留的功能**（稿子上看不见，但代码里不能丢）：
  `LocaleSwitch` 组件、401 与网络错误两种错误文案、按钮 loading 态与 disabled、
  两个输入框的 `autoComplete="username"` / `"current-password"`、`aria-invalid`。
- **3D 背景若用 CSS 3D**：要加 `prefers-reduced-motion` 降级，并确认它不会在低端机上掉帧。
