# 给 Stitch 的 Prompt

**用法**：先发 Prompt A（整页定调），拿到稿子后对不满意的段落用 Prompt B 逐段细化。
配图按 `README.md` 的清单一起上传。

> 为什么不直接贴 `docs/DESIGN.md` 第 6 节：那节里一半是给 DeepSeek 的落地指令
> （Token 命名、CMYK 转换、性能降级），Stitch 不需要，贴进去只会稀释它对视觉要求的注意力。

## Prompt A · 整页定调

```
你是资深产品设计师。改一个 B2B 数据平台的官网落地页，参考 Linear（linear.app）的视觉语言。

【产品】
MWLAB 万象 —— 杜塞尔多夫展览（Messe Düsseldorf）上海公司的 BD 工作台。
用户是会展行业的决策者。产品气质：克制、专业、数据密度高，不是消费级 SaaS。

【现状】
见附图 01：现在是纯白底 + 发丝线分隔的极简版式，信息清楚但太平、没有层次和质感。
要保留这份克制，但加入 Linear 那种「有空气感的高级」。

【页面结构 · 共 7 段】
1. 导航（保持现状，不要改）
2. 首屏 Hero
3. 数据带 + 数据切面（原本是两段，现在合并成一段）
4. 三条业务线
5. 数据管道图（新增）
6. 页脚

【逐段要求】

■ 第 2 段 · 首屏 Hero
参考 Linear 首屏。从下到上三层：柔和渐变或毛玻璃背景 → 悬浮的产品界面 → 大范围低透明度投影。
产品界面用附图 02（真实的数据看板，地图 + 日历 + 数字卡片），不要用插画或抽象图形。
界面顶边可以略微裁出画面，暗示下面还有内容。
文案保持：
  主标题两行：「中国展会市场的」/「结构化盘面」
  副标题：「7,378 个展会品牌 · 4,990 个主办方集团 · 7,703 条届次记录。为杜塞尔多夫展览的业务拓展提供事实基础。」
  主按钮「进入系统」+ 文字链「查看数据覆盖 →」

■ 第 3 段 · 数据带 + 数据切面（合并）
上半部分是一行六个大数字：7,378 展会品牌 / 4,990 主办方集团 / 7,703 届次记录 /
8,145 地理标签 / 501 企业档案 / 12,302 人工核验。
下半部分是 3×2 六块数据面板，小标题为：地理分布、主办方集团、行业结构、规模排名、档期分布、无 2026 年届次的品牌。
整段加一层浅底色，与页面白底拉开层次。
背景加一层「交互式流体扭曲」效果：鼠标移动时背景轻微流动折射。
**流体只能在背景层，数字和文字绝对不能跟着变形** —— 这是数据页，可读性第一。

■ 第 4 段 · 三条业务线
现在是三列纯文字，太平。改成三张带边框的卡片，鼠标悬停时翻转露出背面。
正面：序号（01/02/03）+ 标题 + 一行说明
背面：三个短条目
内容：
  01 并购标的 —— 为杜塞已有品牌寻找中国延展的收购与合作标的
     背面：主办方企业穿透 / 规模与估值锚定 / 深度尽调报告
  02 全新品类 —— 杜塞全球没有、中国市场应该有的空白赛道
     背面：届次断档识别 / 现有玩家盘点 / 可行性评估
  03 项目组支持 —— 为各项目组提供数据工具与合作方对接
     背面：展商线索挖掘 / 合作方撮合 / 定制数据工具

■ 第 5 段 · 数据管道图（新增）
版式参考 Linear 的「Build, review, and ship」那一段：左文右图，或上文下图。
标题：「自组，自建，为 BD 而生」
图的内容是数据管道流程：采集 → 合并 → 治理 → 看板，或者终端里管道跑动的日志感。
不要画成裸代码截图，要让不写代码的人也看得懂价值。

■ 第 6 段 · 页脚
现在只有品牌字标和两行小字，需要扩展：
  - Terms 与 Privacy 两个链接
  - 两个合作方 logo 的位置（留空位即可）
  - 一个 like 按钮，点击时放礼花动效
  - 保留：品牌字标、「Messe Düsseldorf Shanghai · Business Development」、
    「© 2026 杜塞尔多夫展览（上海）有限公司 · 内部系统」、「进入系统 →」、「访问需内部账号」

■ 全页 · 交互反馈
所有可点击的东西（导航锚点、按钮、文字链、卡片、数据面板）都要有 hover 反馈。
过渡 150–200ms ease-out，位移最多 1–2px。不要弹跳，不要缩放整块元素。

【颜色 · 只能用这些】
背景 #ffffff　次级面 #fafafa　侧栏/表头底 #f2f2f2　hover 底 #e6e6e6
发丝线 rgba(0,0,0,0.08)　发丝线 hover rgba(0,0,0,0.21)
主文字 #171717　正文 #4d4d4d　次要 #8f8f8f　最弱 #a8a8a8
主按钮 底 #171717 / 字 #ffffff
渐变和毛玻璃只能在这个中性灰到极浅暖调的范围内做。
**不要引入任何第二个强调色。橙色 #fe5c00 是品牌色，只能出现在左上角 Logo 里，界面其他地方一律不许用。**

【中文排版 · 必须遵守】
1. 中文字重比拉丁低一档（拉丁 600 时中文用 500）
2. 中文绝对不要用负字距（letter-spacing 不能是负值）
3. 中文行高比拉丁高：拉丁 1.4，中文 1.6，长文 1.8
4. 中英混排时中文字号比拉丁小 1px
5. 所有数字用拉丁等宽字体，不要落进中文字体
6. 中文标题不要用 800 字重，会触发伪粗体、边缘发毛
7. 中英之间留 0.25em 间隙

【字号】
11 / 13 / 15 / 18 / 24 / 28 / 44 / 72 px 八级，中文各小 1px。
落地页主标题用 72px，中文 68px。

【圆角】
2 / 4 / 6 / 8 px 四档。卡片用 8px。

【绝对不要做的】
- 不要编任何数据。所有数字和文案用上面给的原文，不要造假展会名、假公司名、假统计
- 不要把中文界面翻译成英文
- 不要加插画、装饰性图标、订阅框、社交媒体图标、开发者署名
- 不要引入第二个强调色
- 不要改导航栏结构和左上角品牌 Logo
- 不要用 Material Design 的配色和组件语言

输出 1440px 宽的桌面版。
```

## Prompt B · 分段细化模板

整页稿出来后，对不满意的段落单独再要。把下面的括号换成具体内容：

```
只重做【第 X 段】，其余保持不变。

不满意的地方：（具体说，例如「投影太重，压住了界面」「卡片翻转的背面信息太挤」）
想要的效果：（具体说，例如「投影范围再大一倍、透明度减半」）

约束不变：颜色只能用之前给的那套，橙色只在 Logo，中文不用负字距，不要编数据。
```

## 拿到稿子后先自查

在交给 Claude Design 深化之前，先看这几条：

| 检查 | 不过关的表现 |
|---|---|
| 有没有编数据 | 出现了没见过的展会名、公司名、统计数字 |
| 橙色跑出 Logo 没有 | 按钮、标签、图表里出现橙色 |
| 中文挤不挤 | 字之间贴在一起 = 套了负字距 |
| 第二个强调色 | 出现了蓝色/绿色等新的高饱和色 |
| 流体动效有没有影响读数 | 数字跟着背景一起扭曲 |
| 是不是 Material Design | 出现胶囊按钮、涟漪效果、大圆角卡片 |

前两条是上一轮踩过的坑：Stitch 上一次编了 43 条假展会名，还把品牌橙降级藏进了
`primary-container`。
