## Objective

Make `public/pitch.html` the primary public-facing entry point. Currently `/` redirects unauthenticated users to `/login`. Change it so unauthenticated users land on `/pitch.html` (the pitch/capability showcase). Authenticated users still go directly to `/dashboard.html`.

Login and dashboard routes stay at `/login` and `/dashboard.html` — they become "sub-routes" under the pitch entry.

## Context

- `public/pitch.html` → served at `/pitch.html` (static file in Next.js public/)
- `public/dashboard.html` → served at `/dashboard.html` (static, main app after login)
- `app/login/page.tsx` → Next.js route at `/login`
- `app/page.tsx` → currently does `redirect('/dashboard.html')` regardless of auth
- `middleware.ts` → already whitelists `/pitch.html` and `/login` from auth checks

## Tasks

### Task 1 — Update `app/page.tsx` root redirect

Read `app/page.tsx`. Current behavior: always redirects to `/dashboard.html`.

Change to:
- If user has valid JWT token (check cookie `token` via `cookies()`) → redirect to `/dashboard.html`
- If no token → redirect to `/pitch.html`

Pattern: use `cookies()` from `next/headers` and check if `token` cookie exists. If yes, redirect to dashboard. If no, redirect to pitch. No JWT verification needed here — middleware handles auth enforcement.

```typescript
import { redirect } from 'next/navigation'
import { cookies } from 'next/headers'

export default async function Home() {
  const cookieStore = await cookies()
  const token = cookieStore.get('token')
  if (token?.value) {
    redirect('/dashboard.html')
  } else {
    redirect('/pitch.html')
  }
}
```
